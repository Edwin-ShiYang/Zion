# Texture

A **Texture** is a structured collection of data, typically a 2D image (texels). In D3D11, textures are general-purpose multidimensional arrays — they can store colors, normals, depth values, or any float data.

关联：[[D3D11.BackBuffer]] [[D3D11.DepthBuffer]]

---

## Texture 只是数据容器

`Texture.Sample()` 永远返回 `float4`（四个浮点数），**GPU 不知道这代表颜色还是法线**。语义由程序员约定：

```hlsl
// Sample the same data; meaning depends on how you interpret it
float3 albedo    = AlbedoTex.Sample(s, uv).rgb;       // As color
float3 normal    = NormalTex.Sample(s, uv).rgb * 2 - 1; // As normal
float  depth     = DepthTex.Sample(s, uv).r;           // As depth
```

## SamplerState（采样规则）

Texture 存数据，**SamplerState 决定怎么读这个数据**——当 UV 落在两个像素之间，或者超出 0~1 范围时，该怎么处理。

```hlsl
SamplerState ColorSampler
{
    Filter   = MIN_MAG_MIP_LINEAR;
    AddressU = WRAP;
    AddressV = WRAP;
};
```

### Filter（过滤方式）

UV 坐标是连续的小数，Texel 是离散的格子，UV 落在两个 Texel 之间时：

| Filter | 效果 |
| :--- | :--- |
| `MIN_MAG_MIP_LINEAR` | 线性插值，平滑，无锯齿 |
| `MIN_MAG_MIP_POINT` | 最近邻，像素化/马赛克 |
| `ANISOTROPIC` | 各向异性，斜视角最清晰，开销最大 |

```
LINEAR（平滑）：    POINT（像素化）：
  ░░▒▒▓▓██           ░░░░▓▓▓▓
  ░░▒▒▓▓██           ░░░░▓▓▓▓
  平滑过渡            硬边缘
```

三个字母 `MIN_MAG_MIP` 分别对应：
- **MIN**：纹理缩小时（远处）
- **MAG**：纹理放大时（近处）
- **MIP**：Mipmap 层级切换时

### AddressMode（寻址模式）

UV 超出 0~1 范围时：

| 模式 | 效果 | 适用场景 |
| :--- | :--- | :--- |
| `WRAP` | 循环平铺 | 地板、砖墙等重复纹理 |
| `CLAMP` | 拉伸边缘像素 | UI、精灵图 |
| `MIRROR` | 每次越界镜像翻转 | 对称图案 |
| `BORDER` | 填充指定边框颜色 | Shadow Map 采样越界 |

---

## `SamplerMode::BILINEAR_WRAP`

`SamplerMode::BILINEAR_WRAP` usually means bilinear filtering + wrap address mode / 通常表示“线性插值采样 + UV 越界重复平铺”。

```text
BILINEAR = bilinear filtering / 采样周围 4 个 texels 做插值，结果更平滑
WRAP     = wrap address mode / UV 超出 0..1 时循环重复 texture
```

UV wrap 直觉：

```text
uv = 0.2  -> sample 0.2 / 正常采样
uv = 1.2  -> sample 0.2 / 超过 1 后重复
uv = 2.7  -> sample 0.7 / 重复多次后取小数部分
uv = -0.3 -> sample 0.7 / 负数方向也循环
```

常见用途：

```text
ground texture / 地面贴图
wall texture / 墙面贴图
brick texture / 砖块贴图
wood grain / 木纹贴图
```

不适合 shadow map 的原因：

```text
WRAP on shadow map = shadow UV outside 0..1 samples the opposite side / shadow UV 越界时会采到另一边的 depth
This can create incorrect shadows / 这会产生错误阴影
```

Shadow map 第一版通常更适合：

```cpp
// Use point sampling and clamp UVs for the first shadow map version
SamplerMode shadowSamplerMode = SamplerMode::POINT_CLAMP;
```

## Texture 与 Sampler 分离

同一张纹理可以用不同规则采样，同一个 Sampler 可以用于不同纹理：

```hlsl
// Same texture, two sampling results
float4 smooth  = MyTex.Sample(LinearSampler, uv);
float4 pixelated = MyTex.Sample(PointSampler, uv);

// Different textures, same sampler
float4 albedo  = AlbedoTex.Sample(ColorSampler, uv);
float4 normal  = NormalTex.Sample(ColorSampler, uv);
```

## D3D11 绑定方式

```cpp
// Bind texture SRV to t0
context->PSSetShaderResources(0, 1, &textureSRV);

// Bind sampler to s0
context->PSSetSamplers(0, 1, &samplerState);
```

```hlsl
// Matching HLSL declarations
Texture2D  MyTexture : register(t0);
SamplerState MySampler : register(s0);

float4 color = MyTexture.Sample(MySampler, uv);
```

## 上传图片数据到 Texture

`UpdateSubresource` uploads image pixel data from CPU memory to a GPU texture / 把 CPU 内存里的图片像素数据上传到 GPU texture。

```cpp
unsigned int rowPitch = (image.m_isHDR ? sizeof(Vec4) : sizeof(Rgba8)) * image.GetDimensions().x;
m_deviceContext->UpdateSubresource(newTexture->m_texture, 0, nullptr, image.GetRawData(), rowPitch, 0);
```

Parameter mapping / 参数一一对应：

```text
pDstResource   = newTexture->m_texture
DstSubresource = 0
pDstBox        = nullptr
pSrcData       = image.GetRawData()
SrcRowPitch    = rowPitch
SrcDepthPitch  = 0
```

Plain-language mapping / 更直观地看：

```text
newTexture->m_texture = target GPU texture / 要更新哪张 GPU texture
0                     = mip level 0 / 更新原始尺寸那层 mip
nullptr               = whole subresource / 不指定局部区域，整张 texture 都更新
image.GetRawData()    = source CPU pixel data / CPU 里的图片像素数据，从这里开始拷贝
rowPitch              = bytes per source row / CPU 图片数据中一行像素占多少 bytes
0                     = source depth pitch / 3D texture 才用；Texture2D 填 0
```

`rowPitch` means bytes per row / `rowPitch` 表示 CPU 图片数据中每一行占多少 bytes：

```text
rowPitch = bytesPerPixel * imageWidth
```

RGBA8 image / 普通 RGBA8 图片：

```text
sizeof(Rgba8) = 4 bytes / pixel
rowPitch = 4 * width
```

HDR image / HDR 图片：

```text
sizeof(Vec4) = 16 bytes / pixel
rowPitch = 16 * width
```

One-line summary / 一句话：`UpdateSubresource(texture, 0, nullptr, pixels, rowPitch, 0)` uploads the whole CPU image to mip level 0 of the GPU texture / 把 CPU 里的整张图片上传到 GPU texture 的 mip level 0。

If the texture was created with a full mip chain, generate mipmaps through its SRV / 如果 texture 创建了完整 mip chain，之后可以通过 SRV 生成 mipmaps：

```cpp
m_deviceContext->GenerateMips(newTexture->m_shaderResourceView);
```

相关 descriptor 设置见 [[D3D11.D3D11_TEXTURE2D_DESC#Image Texture 示例]]。

## Texture 的双重用途

同一张纹理可以作为输入（SRV）也可以作为输出（RTV），参见 [[D3D11.RenderTarget]]：

```
作为 SRV → 在 Shader 里采样（读）
作为 RTV → 作为 Render Target 被写入（写）

⚠️ 不能同时读写，切换前必须解绑
```
